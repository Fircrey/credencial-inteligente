CREDENCIAL INTELIGENTE - PAQUETE PARA GITHUB PAGES

Archivos:
- index.html: prototipo principal.
- support.js: motor de ejecucion requerido por el HTML.

IMPORTANTE:
No separes ni elimines support.js. Ambos archivos deben quedar en la misma carpeta.

Para probarlo localmente, abre index.html con Chrome y mantente conectado a internet.
El runtime carga React desde un CDN y la interfaz carga fuentes e iconos externos.

Para publicarlo con GitHub Pages, sube los tres archivos a la raiz de un repositorio y activa Settings > Pages > Deploy from a branch > main > /(root).
Luego comparte la URL que GitHub Pages genere.
